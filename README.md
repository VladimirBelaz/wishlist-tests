Автоматизированные UI-тесты для приложения [WishList](https://wishlist.otus.kartushin.su/).

## О проекте
Проект содержит автоматизированные тесты для веб-приложения «Список желаний». Покрыты следующие функциональности:

- **Регистрация** – успешная регистрация, проверка уникальности имени/email, валидация длины полей (3–50 для username, ≥6 для password), пустые поля, некорректный email.
- **Авторизация** – вход с корректными/некорректными данными, редирект на защищённые страницы, валидация пустых полей.
- **Списки желаний** – создание, просмотр деталей, удаление одного или всех списков.
- **Подарки** – добавление подарка в список с заполнением всех полей (название, описание, цена, ссылки).

## Технологии
- **Java 22**
- **Maven** – сборка и управление зависимостями
- **JUnit 5** – тестовый фреймворк
- **Selenium WebDriver** – взаимодействие с браузером
- **WebDriverManager** – автоматическое управление драйверами
- **Log4j2** – логирование
- **PageObject pattern** – архитектура тестов
- Кастомные исключения и ассерты

## Запуск тестов

### Параметры запуска
Тесты используют системные свойства, которые можно передавать через командную строку или в `pom.xml`:

| Свойство   | Описание                              | Значение по умолчанию                    |
|------------|---------------------------------------|------------------------------------------|
| `BASE_URL` | Базовый URL приложения                | `https://wishlist.otus.kartushin.su`     |
| `USERNAME` | Имя пользователя для логина           | `vladimirbv` (замените на свои данные)   |
| `PASSWORD` | Пароль пользователя                   | `E17wfz25Zm`                             |
| `browser`  | Браузер (`CHROME`, `FIREFOX`, `EDGE`) | `CHROME`                                 |
| `headless` | Headless-режим (`true`/`false`)       | `false`                                  |

### Команды Maven

# Запуск всех тестов (Chrome)
```mvn clean test```
# Запуск в Firefox
```mvn clean test -Pfirefox-tests```
# Запуск в Edge
```mvn clean test -Pedge-tests```
# Запуск конкретного тестового класса
```mvn clean test -Dtest=WishListTest```
# Запуск одного теста
```mvn clean test -Dtest=WishListTest#testCreateWishList```
# Переопределение параметров
```mvn clean test -DUSERNAME=myuser -DPASSWORD=mypass -Dheadless=true```

Примечание: по умолчанию используется браузер Chrome. Для Firefox или Edge используйте соответствующий профиль.
### Поддерживаемые браузеры
Google Chrome – профиль chrome-tests (активен по умолчанию)

Mozilla Firefox – профиль firefox-tests

Microsoft Edge – профиль edge-tests

### Логирование
Логирование настроено через Log4j2. Уровень логирования можно изменить в файлах log4j2.xml (в папке src/main/resources).
В консоль выводятся информационные сообщения о каждом действии и результате проверки, что упрощает отладку и анализ выполнения тестов.

### Кроссбраузерное тестирование
Реализовано через профили Maven и фабрику WebDriverFactory. При необходимости можно легко добавить поддержку других браузеров, расширив фабрику.
